# ClarityKey 0.5.3-beta

Дата: 26.11.2026

## Исправлено

- Повторное нажатие `"` после длинного русского текста внутри `«…»` теперь вводит закрывающую кавычку `»`, а не вторую открывающую `«`.
- Автотипографика учитывает до 256 символов локального контекста только при выборе направления кавычки; для остальных замен сохранено короткое окно в 4 символа.
- Текст, скопированный при скрытой клавиатуре, теперь сохраняется при первой тихой синхронизации системного буфера после открытия ClarityKey.
- Стартовая синхронизация не показывает старый текст как новый quick-chip; фильтрация конфиденциальных элементов буфера сохранена.

## Проверки

- Добавлен регрессионный тест для длинной фразы между открывающей и закрывающей кавычками.
- GitHub Actions выполняет `testDebugUnitTest`, Android Lint и подписанную `assembleRelease` сборку.
